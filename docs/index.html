차단문

선택한 프로그램을 내가 정한 시간까지 차단하는 Windows 프로그램

버전 정보를 불러오는 중 차단문 다운로드

Windows 10 / Windows 11

설치 방법

  1. 위 버튼을 눌러 설치파일을 다운로드합니다.
  2. 다운로드한 설치파일을 실행합니다.
  3. 안내에 따라 설치를 진행합니다.
  4. 차단문을 실행하고 구매 시 받으신 라이선스 키를 입력합니다.

설치와 차단 시작에는 관리자 권한이 필요합니다.

라이선스

차단문을 사용하려면 구매 시 제공된 라이선스 키가 필요합니다. 한 번 입력하면 다시 입력하지 않아도 되며, 인증은 인터넷 연결 없이 사용자의 PC 안에서만 이루어집니다.

라이선스 키는 구매자 본인의 사용을 위해 제공됩니다. 키 또는 이를 이용해 활성화한 프로그램을 제3자에게 공유·판매·대여하거나 무단으로 배포할 수 없습니다.

라이선스 키는 재설치할 때 다시 필요하므로 보관해주세요. 자세한 이용조건은 스마트스토어 상품 상세페이지를 확인해주세요.

차단을 시작하기 전에

차단문은 설정한 종료 시각까지 선택한 프로그램의 실행을 제한합니다. 시작하기 전에 아래를 확인해주세요.

  • 차단할 프로그램이 올바르게 선택되었는지
  • 차단 종료 시각이 올바르게 설정되었는지
  • 업무나 학업에 필요한 프로그램이 실수로 포함되지 않았는지

Windows 보안 경고가 뜰 때

설치파일을 실행하면 아래와 같은 파란 화면이 표시될 수 있습니다. Windows가 아직 널리 알려지지 않은 프로그램에 대해 표시하는 안내이며, 오류가 아닙니다.

이런 화면이 표시됩니다 Windows의 PC 보호
Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

진행하려면 아래 순서를 따라주세요.

  1. 추가 정보를 누릅니다.
  2. 앱 이름이 인지 확인합니다.
  3. 실행을 누릅니다.

게시자는 알 수 없는 게시자로 표시됩니다. 차단문은 아직 코드 서명 인증서를 사용하지 않기 때문이며, 파일에 문제가 있다는 뜻은 아닙니다. 확인하실 부분은 게시자가 아니라 파일 이름입니다.

브라우저에서 다운로드할 때도 비슷한 경고가 표시될 수 있습니다. 이때는 유지 또는 계속을 선택하면 됩니다.

파일 이름이 위와 다르다면 실행하지 마시고 이 페이지에서 다시 받아주세요. 이 페이지 외의 경로로 받은 파일은 안전을 보장할 수 없습니다.

재다운로드

기존 구매자도 이 페이지에서 최신 버전을 다시 다운로드할 수 있습니다. PC를 바꾸거나 프로그램을 다시 설치할 때도 이 페이지에서 받으시면 됩니다.

자주 묻는 질문

인터넷 연결이 필요한가요?

설치파일을 내려받을 때만 필요합니다. 라이선스 인증과 차단 기능은 인터넷 없이 동작하며, 어떤 정보도 외부로 전송하지 않습니다.

라이선스 키를 잃어버렸어요.

스마트스토어 톡톡으로 문의해주세요. 주문 내역을 확인한 뒤 안내해드립니다.

PC를 바꿨습니다. 다시 설치해도 되나요?

이 페이지에서 설치파일을 받아 설치한 뒤, 가지고 계신 라이선스 키를 다시 입력하시면 됩니다.

실수로 필요한 프로그램을 차단했어요. 취소할 수 있나요?

차단문은 스스로 해제하지 못하도록 만들어진 프로그램이라, 설정하신 종료 시각까지는 해제할 수 없습니다. 차단을 시작하기 전에 선택한 프로그램과 종료 시각을 꼭 확인해주세요.

차단 중에 PC를 껐다 켜면 어떻게 되나요?

차단이 그대로 유지됩니다. 재부팅이나 강제 종료로는 풀리지 않으며, 설정한 종료 시각이 지나면 자동으로 해제됩니다.

차단 중에 차단문을 삭제하면 차단이 풀리나요?

풀리지 않습니다. 다만 설정한 종료 시각이 되면 차단문이 없어도 차단은 자동으로 해제됩니다. 삭제한 뒤에는 남은 시간을 확인할 수 없습니다.

차단 시간이 끝났는데 프로그램이 계속 안 열려요.

차단 해제는 종료 시각 직후 처리되며, PC가 꺼져 있었다면 다시 켠 뒤 몇 분 안에 해제됩니다. 그래도 열리지 않으면 차단문을 한 번 실행해주세요. 남아 있는 차단을 정리합니다.

차단문을 실행할 때 권한을 묻는 창이 떠요.

차단을 걸고 푸는 데 Windows 설정을 변경해야 하므로 관리자 권한이 필요합니다. 차단을 시작하는 순간에만 표시되며, 프로그램을 켜기만 할 때는 나타나지 않습니다.

백신이 차단문을 의심스러운 프로그램으로 표시해요.

차단문은 프로그램 실행을 막기 위해 Windows 설정을 변경하므로 일부 백신이 이를 민감하게 볼 수 있습니다. 이 페이지에서 받으신 파일이라면 그대로 진행하셔도 됩니다. 계속 문제가 있으면 톡톡으로 문의해주세요.
